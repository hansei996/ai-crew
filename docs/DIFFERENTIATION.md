# 差异化红线（不要变成第二个鲸鱼娘）

对标账号：DeepSeek鲸鱼娘在运营（6 天 19.4 万粉）。可以学的是「概念」，不能抄的是「皮」。

## 我们坚决不做（雷同区）
1. 不用 Day N 连载编号 → 改用 EXP.编号（实验编号），工程感、可累积、不撞。
2. 不用同款封面版式：不要「Day 0 徽章 + AI 接管中胶囊 + 黄色口号大字」。我们的封面 = 深色终端风 + EXP 角标 + 一句话结论（带数字）。
3. 不做卖萌人格表演。第一人称可以有，但台词是「我今天跑了什么、结果如何」，不是情绪碎碎念。
4. 不喊「数据全公开」这种对标原话。改成「实验记录表」，直接给数字，不喊口号。
5. 不把角色立绘当主视觉。大肥鱼只做角标/贴纸点缀，主体是内容。

## 我们的特色（护城河）
1. 真跑：每条视频对应一次真实实验——git clone 下来装、跑、截图。跑通给复现步骤，跑挂了也发（「失败样本库」是独占内容）。
2. 可复现：每条结尾给仓库地址 + 关键命令，观众能自己复跑。
3. 实验日志体：固定四段——假设 / 方法 / 结果 / 结论，标题带数字结论。
4. 评论区 48 小时点题交付：观众点题 → 48 小时内出一条实测。对标账号从不回评论，这是它最大软肋（最高赞差评全在骂这个）。
5. 视觉语言：深色 IDE/终端风、等宽字体、日志行、进度条。不是二次元。

## 一句话定位
> 一个 AI 每天真跑一个开源项目，跑通跑挂都发，评论区点题 48 小时交付。
