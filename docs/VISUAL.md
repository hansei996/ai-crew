## 0.5 第一条硬指标：节奏在「画面内部」，不在剪辑刀上

**leads 结论（research 实抓支撑）：我们的目标不是「多切几刀」，而是「每个画面内部要活」。**

| 事实（research 实测） | 数字 |
|---|---|
| 对标全片剪辑次数 | Day5 55.07s 内 **2 次**（0.010/s）｜Day4 4 次（0.015/s）｜Day3 1 次（0.004/s） |
| 降到阈值 0.12 复测 | **零命中** → 全片无叠化/淡入淡出，**只有硬切** |
| 但它卡片内元素替换率 | Day5 **0.38/s**（23.0 次/分）｜Day4 0.31/s｜Day3 0.26/s |

→ **硬指标：每个画面 3–5 秒必须有一次有效变化（0.2–0.33 次/秒）**；「有效变化」＝元素替换 / 字幕换行 / 数字滚动 / 强调词放大 / 截图位移，**不包括**周期性抖动与无意义闪烁。
→ 反推：单卡 ≤8 秒（现状 8–15 秒），一卡之内至少布 2 个变化点。lab 的动效设计按此表出方案。

## 1. P0-0 首帧不许是黑板（最高优先级，压过所有特效）

**实测事实**：`episodes/ep01/out/ep01.mp4` 第 0 帧 = **6,154 B / YAVG 16（平场）**；t=1.2s 帧 = **1,425,872 B / YAVG≈48.8**。
（PMO 用 `ffmpeg -ss 0 -frames:v 1` + `signalstats` 独立复核；lead 独立测到 6,154 B / YAVG 16，一致。）
→ B站 列表页/推荐卡取首帧 → **我们所有片子的门面是一块黑板**。这是分发问题，不是画质问题。

**硬规则（机器可校验）**
1. 第 0 帧（**采样点 t=0**，不是 t=0.05）必须已有可见内容（EXP.NNN 角标 + 至少 1 个字符/数字）。**判据（与底色无关，黑底/亮底同一套）**：
   - **spread（YMAX − YMIN）≥ 40** —— 帧内确有亮度差
   - **内容像素占比 ≥ 0.1%** —— 与背景众数 `|Y − bg| > 20` 的像素数 ÷ 总像素（1920×1080 = 2,073,600 → 门槛 2,074 px）
   - **帧体积不再作为判据**（只记录）：体积随编码与画面细节波动，用它当门槛会误杀低码率版式、也拦不住噪声帧。
   - **唯一实现：`publisher/lib/p0.mjs`**（已接 `publish_gate` 第 13/14 项）。**能阻断发布的那个实现才是唯一实现**；离线脚本与闸门用两套实现＝「验收通过」与「能不能发」变成两件事。任何人报首帧数字**必须注明「由 p0.mjs 生成」**，否则不采信。
   - 校准实测（p0.mjs 口径，ops 与 PMO 两套独立实现交叉一致）：**A 245 / 0.373% PASS**｜**C 178 / 0.616% PASS**｜**demo15 200 / 2.855% PASS**｜**exp000（线上旧稿）0 / 0.000% FAIL**。
   - **余量要求（新）**：spread 不得踩着 40 过线——**探针/成片一律要求 spread ≥ 80**，否则上线后会随机失败（最难查的一类 bug）。已知需修：探针 B 实测 spread **45**（A 245 / C 178 / D 254）。
   - **亮底版式（如 D）不需另设阈值**：内容占比与 spread 已与底色无关。（此前 ops 提议的「按调色板算各自 YAVG 下限」随之作废。）
2. 淡入从 `-0.25s` 起算，或首帧直接置 1.0 —— 两者选一，**必须实测**并记录选择。
3. 渲染完成后自动抽 t=0 帧校验，**不达标非零退出**；并接入 `publisher/publish_gate.mjs` 第 14 项。
4. 责任人：infra（renderer 层根因）+ ops（闸门第 14 项）｜P0

## 2.5 上屏数字规则（每个数字都必须能当场对上）

1. **每个上屏数字必须有出处**：文件 + 行号，或 JSON 路径（例：ev2.txt L22–23｜raw_doctor_full.json:tools）。无出处的数字**不得上屏**；叙述性文档（knowledge/*.md 的叙述）**不算原始证据**。
2. **禁止新造分母**：73 是 available（ev2 与 doctor JSON 皆为 available，不是 total）→ **不许写成「73/73」**；42/42 可写，因为 doctor JSON 里 tools 42 项且 usable 全为 yes。
3. **8 秒短卡优先挂「一眼可对上」的数**：`73 capabilities · 0 required missing`（ev2:L22-23 可直接看到）优于需要翻 JSON 才能验的等价数字。
4. **裸数字禁止**：即使是真数，若在观众可见资料里核不到（如 1.26 秒仅见于 C01.md 叙述、且复跑得 1.723 s 不复现）→ 不用。
5. **不稳定指标不当事实**：同一命令实测在 3 倍区间内波动的数（例：contract 耗时 **0.62s 热 / 1.06s 冷 / 1.72s 另一环境 = 2.8 倍**）**不配进片子**，改报稳定事实（如「42 个工具」）。判断标准：同一机器重复 3 次，极差/中位 > 30% 即弃用。
6. **派生值不可检索**：聚合类数字（N/N、百分比、合计、均值）**不要靠 grep 找**，必须重算——定分母、定判据、逐项计数。**「搜不到」不等于「不存在」，只等于「它不是字面串」。**（实例：42/42 在 `raw_doctor_full.json` 里根本没有这个字面串，它是「42 项 × 全部 usable=yes」算出来的。）这条与「判定不存在前换一种格式再查」互补：那条防「查的方式错」，这条防「查的对象根本不是字面量」。
## 3. 立绘红线（本轮方案变更）

1. **本轮不引入任何角色立绘**，先把排版、动效、转场、真实画面做到位。**硬原因**：`assets/*.png` 那 4 张鱼图在台账里是「来源不明→禁用」，assets 闸会直接 throw，也就是说现在连贴都贴不上。
2. 立绘只能来自「用户提供 / 用户授权 / 我们自绘」，**拿到授权前不占位、不预埋**。
3. `render.mjs:267-269` 现行 sticker = `scale=500`（26% 屏宽）+ 水平居中 + `70px·sin(2.4t)` 循环抖动 → **撞 persona 黑名单第 1、2 条，必须改**：角落小窗、≤8% 屏面积（≤165,888 px²）、无周期性抖动（入场/结论各一次位移）。
4. 若日后启用，参数上限（persona 白名单，可直接喂渲染器 `scene.overlay`）：
   - A 说话角落小窗：wPx 280–360、corner=br、y=0.62H、opacity 0.85–0.95、3–8s
   - B 结论弹入：wPx 400–520、y=0.30H、scale 0.92→1.00 / 120ms ease-out、回弹 ≤1.03、单次 ≤3.5s
   - C 失败塌下：y 0.30H→0.60H、旋转 0→−6°、opacity 1.0→0.55、落地禁弹跳

5. **一票否决**（评审样片用）：①立绘 >8% 屏或进入中心安全框 0.25–0.75W × 0.25–0.70H；②删掉立绘后结论理解不变（纯装饰）且累计 >12s 或 >3 次/期。

### 5.1 字体层级表（**「PPT 感」第一大来源就是全片微软雅黑**）

本机字体实况（PMO 实测目录 `C:\Windows\Fonts`：**582 个字体文件**；lead 口径 384 应为家族数/去重后——口径差异已记）：许可干净且已确认存在——

| 用途 | 字体 | 字重 | 字号 | 字距 | 行高 | 为什么 |
|---|---|---|---|---|---|---|
| 主标题 | **NotoSansSC-VF.ttf**（SIL OFL 可商用，17.4 MB 可变字重） | 700–800 | 96–112 | −1%~0 | 1.15× | 可变字重可做逐字加粗；比雅黑中性、不塌 |
| 副标题 | NotoSansSC-VF | 400–500 | 38–46 | +1% | 1.3× | 同族靠字重分层级 |
| 数字 / 数据 | **bahnschrift.ttf**（DIN 风格可变字宽） | 600 | 68–160 | 0 | 1.0× | tabular 对齐，仪表感来源 |
| 等宽 / 终端 | **CascadiaMono.ttf**（MIT 可商用）／CascadiaCode.ttf | 400 | 40–44 | 0 | 1.45× | 真终端字体，直接去掉 PPT 味 |
| 正文 / 卡片 | NotoSansSC-VF | 400 | 40–56 | 0 | 1.35× | |
| 字幕（ASS） | CascadiaCode + NotoSansSC 回退 | 400 | 56–59 | +0.5% | 1.3× | 保持 ass 56 |
| 角标 EXP.NNN | CascadiaMono | 700 | 44–52 | +8%（拉开） | 1.0× | 现值 kicker 34 → 必须改 |

**硬指标（lead 定）**：`等宽讲证据，bahnschrift 讲数字，NotoSans 讲人话`；**CascadiaMono 作为主角时，文字量占比必须 ≥50%**，否则就会滑向 B（PPT 路线）。评片时按字符数统计，可机器校验。
**ASS 字幕字体规则（lab 实测，2026-10-25）**：ASS `Style: Fontname` 必须填 **family 名**，不能填字体文件名。
| 填法 | 实际解析 | 结果 |
|---|---|---|
| `NotoSansSC-VF`（文件名） | **ArialMT**，报 `Glyph 0x5927 not found`（「大」缺字） | ❌ **正片会豆腐块** |
| `Noto Sans SC` + Bold=0 | fontselect (Noto Sans SC, **400**) -> NotoSansSC-Thin | ⚠️ 只有细体 |
| `Noto Sans SC` + Bold=1 | fontselect (Noto Sans SC, **700**) -> **仍是 NotoSansSC-Thin** | ❌ **VFO 只向 DirectWrite 暴露 Thin 一个 face，粗体请求被静默降级**（lab 实测 2026-10-25） |
| `Microsoft YaHei` / `Microsoft YaHei Bold` | MicrosoftYaHei / msyhbd（**有真粗体**） | ✅ **ASS 字幕的正式取值**（本轮裁决） |

→ 任何中文 ASS 字幕**上线前必须做一次缺字检查**（`ffmpeg -v verbose` 看 fontselect 与 Glyph missing 日志），缺字即视为阻断缺陷。

## 8. 转场选择规则（语义优先，不是炫技）

| 转场 | 语义 | 时长 | 何时用 |
|---|---|---|---|
| 硬切 | 时间推进 / 换论点 | 0 ms | **默认**。对标全片只有硬切（实测阈值 0.12 无命中） |
| 滑动（slide） | 空间连续 / 并列比较 | 240 ms | 连续两条证据、A/B 对比 |
| 缩放推进（zoom-in） | 进入细节 | 300 ms | 从整屏 → 截图局部（`zoompan` 已在用） |
| 遮罩揭示（mask） | 揭示证据 / 反转 | 400 ms | 「跑挂」结论出现时揭开错误日志 |

### 15.1 探针 D 的三条硬约束（lead 直定，越界即撤）

> 为什么保留 D：用户两次说「搓」的同时说的是「**没人味**」。我们所有版本都是深色科技风——**那正是「没人味」的视觉同义词**。排除 D 等于排除唯一可能救这条问题的方向。

1. **手写只能是「批注」，不能是「正文」**：正文/标题/数字一律用排版字体（NotoSansSC / Cascadia）；手写体只允许出现在旁注、箭头、圈选这类「后来加上去的痕迹」，**单画面 ≤2 处**。理由：全手写＝小红书笔记风；批注＝工程师在自己笔记上做记号，那才是我们的身份。
2. **荧光笔只准高亮「数字与命令」**：高亮 `42` / `0.32s` / `ok: 73 capabilities` 可以；高亮情绪词（「爽」「绝了」）**一律否决**。理由：高亮是注意力工具，高亮情绪就是卖萌。
3. **纸感不能是「米黄 + 圆角 + 贴纸」三件套**：纸纹低对比、**冷灰白（不是暖黄）**、**无圆角卡片**、**无贴纸元素**；质感来自纤维噪点与轻微透印，不来自颜色。这条最容易滑向小红书。

> 注：原 §15 探针表中 D 的配色写作 #F5F1E6（偏暖）。**按约束 3 修正为冷灰白系：`#EDEDEA` / 纸纹亮度 ≤+6%**；文案表内的暖色值作废。

## 16. 声音设计（目前为零，是「精美」的一半）

全部 ffmpeg 程序化合成（无素材＝无版权问题）：

| 事件 | 合成 | 时长 | 音量 | 责任人 |
|---|---|---|---|---|
| 转场 whoosh | anoisesrc + 带通扫频 + 指数包络 | 180–260 ms | −18 dB | infra |
| 打字 click | sine 1800 Hz + 5 ms 门限 | 8–12 ms/字 | −22 dB | infra |
| 结论落点 bass hit | sine 55 Hz + 快起慢落 | 300 ms | −14 dB | infra |
| 进度条 rise | sine 滑音 220→880 Hz | = 进度条时长 | −20 dB | infra |
| 环境底噪 | anoisesrc=color=brown | 全片 | −34 dB | infra |

规则：每 3–5 秒至少一个声音事件（与画面有效变化同拍）；结论卡必须有 bass hit；不许循环 BGM（与「无周期性运动」一致）。

## 18. 缓动曲线（现在只有线性淡入）

| 曲线 | 表达式（ffmpeg 可用） | 用于 |
|---|---|---|
| ease-out | 1-pow(1-t,3) | 卡片入场、结论弹出 |
| ease-in-out | (t<0.5)?4*t*t*t:1-pow(-2*t+2,3)/2 | 转场、字距展开 |
| 弹性 overshoot | 1+1.7*pow(t-1,3)+0.7*pow(t-1,2)（钳到 1.03） | 强调词、数字落定 |
| 阶梯 8 档 | floor(t*8)/8 | 进度条、计数器、仪表读数 |

规定：同一镜头内不得混用超过 2 条曲线；结论卡必须用 ease-out 或弹性，禁用线性（线性＝机械感）。
